
# Replica

Studio de création vidéo et image avec IA, en application web responsive et application Android.

**Statut : phase de planification. Aucun code pour l'instant.**

## Objectif

Réunir montage vidéo et génération d'images et de vidéos par IA, avec un budget de départ de 0 € par mois.
